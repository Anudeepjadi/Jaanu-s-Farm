# 🥛 Jaanu's Farm - Fresh Milk Delivery App

> Premium Fresh Milk Delivery at Your Doorstep

A modern Flutter-based mobile application for ordering and receiving fresh milk delivery from Janus Farm. Built with a clean user experience, order management, and real-time delivery updates.

---

## ✨ Features

- 🎯 Easy ordering experience
- 📍 Real-time delivery tracking
- 🔔 Order notifications and updates
- 💳 Secure checkout and payment flow
- ⭐ Ratings and reviews
- 🏠 Saved delivery addresses
- 💰 Offers and discounts
- 📅 Scheduled recurring deliveries

---

## 🚀 Getting Started

### Prerequisites

- Flutter SDK: https://docs.flutter.dev/get-started/install
- Android Studio / Xcode
- Git

### Install

```bash
git clone https://github.com/Anudeepjadi/Anudeep.git
cd Anudeep
flutter pub get
```

### Run the app

```bash
# Android
flutter run -d android

# iOS
flutter run -d ios

# Web
flutter run -d web
```

### Build release

```bash
flutter build apk --release
flutter build ios --release
```

## 🧠 How it works

1. User signs in or creates an account.
2. User browses fresh milk products and selects quantity.
3. Product is added to the cart.
4. User chooses delivery address and payment method.
5. Order is confirmed and payment is processed.
6. Delivery partner receives the request.
7. User tracks live delivery status.
8. Order is delivered and feedback is collected.

```text
Login → Browse → Cart → Checkout → Confirm → Track → Deliver
```
